# 뷰니스 공동구매 사업부 모니터링 시스템

**버전:** v1.0 (MVP) | **업데이트:** 2026-08 | **상세 설계:** [01_설계서.md](01_설계서.md)

인스타그램·유튜브 등에서 진행되는 공동구매를 카테고리별·셀러별로 모아보고,
상세정보(제품·채널·매출)와 히트 예상 인사이트를 확인하는 사내 대시보드입니다.

---

## 구성

| 파일 | 설명 |
|---|---|
| `01_설계서.md` | 전체 아키텍처·데이터모델·자동화 전략·예측모델 설계 문서 |
| `generate_sheet.mjs` | 구글시트 업로드용 xlsx 템플릿 생성 스크립트 |
| `공동구매_모니터링_템플릿.xlsx` | 생성된 템플릿 (Google Sheets로 업로드해서 사용) |
| `dashboard/index.html` | 사내 웹 대시보드 (정적 페이지, 구글시트를 실시간 조회) |

## 셋업 순서 (최초 1회)

1. **구글시트 업로드**
   `공동구매_모니터링_템플릿.xlsx` 를 Google Drive에서 "Google Sheets로 열기"로 업로드합니다.

2. **공유 설정**
   파일 → 공유 → "링크가 있는 모든 사용자(뷰어)" 또는 사내 워크스페이스 도메인으로 제한 공유.

3. **웹에 게시**
   파일 → 공유 → 웹에 게시(Publish to web) → 전체 문서 게시.

4. **시트ID / gid 확인**
   - 주소창 URL 중 `https://docs.google.com/spreadsheets/d/`**`이 부분`**`/edit#gid=...` 이 시트ID입니다.
   - 각 탭(기본가정/카테고리마스터/셀러마스터/채널마스터/공동구매마스터/시장수요트래킹/예측점수/대시보드)을
     클릭하면 URL 끝의 `gid=숫자`가 바뀝니다. 필요한 5개 탭의 gid를 각각 기록하세요:
     `공동구매마스터`, `셀러마스터`, `카테고리마스터`, `채널마스터`, `예측점수`

5. **대시보드 설정값 입력**
   `dashboard/index.html` 상단 `<script>` 안의 `CONFIG` 객체를 수정합니다.
   ```js
   const CONFIG = {
     SHEET_ID: "실제_시트ID",
     GID: {
       gonggu:   "123456",  // 공동구매마스터
       seller:   "234567",  // 셀러마스터
       category: "345678",  // 카테고리마스터
       channel:  "456789",  // 채널마스터
       score:    "567890",  // 예측점수
     },
   };
   ```

6. **배포**
   신규 GitHub 저장소를 만들어 이 폴더 전체를 push 하고, Settings → Pages 에서 GitHub Pages를 활성화하면
   `https://{계정}.github.io/{저장소명}/dashboard/` 링크로 전 직원이 접속 가능합니다.
   (로컬에서만 우선 확인하려면 `dashboard/index.html` 을 브라우저로 직접 열어도 됩니다.)

## 담당자별 입력 가이드 (구글시트)

| 시트 | 담당 | 주기 |
|---|---|---|
| **공동구매마스터** | 발견/진행 담당자 전원 | 신규 공구 발견 즉시 |
| **셀러마스터 / 채널마스터** | 마케팅팀 | 신규 셀러·채널 등장 시 (공동구매마스터 입력 전에 먼저 등록) |
| **시장수요트래킹** | 마케팅/사업개발 | 주 1회 (오픈마켓 베스트, 홈쇼핑 편성, 검색트렌드 체크) |
| **기본가정** | 사업부 리더 | 예측점수 가중치 조정 필요시 |
| **카테고리마스터** | 사업부 리더 | 신규 카테고리 필요시 |
| **예측점수 / 대시보드** | — | 전부 수식, 직접 입력 금지 |

셀 색상 규칙: 🟡 직접 입력 / 🔵 수식 자동계산(수정 금지).

## 자주 발생하는 문제

**Q. 대시보드에 "설정이 필요합니다" 배너만 뜬다**
→ `dashboard/index.html`의 `CONFIG.SHEET_ID`, `CONFIG.GID` 값이 비어있거나 플레이스홀더 그대로입니다. 셋업 순서 4~5번을 확인하세요.

**Q. 공동구매마스터에 신규 행을 추가했는데 대시보드에 안 보인다**
→ gviz 조회 범위가 `A3:V1000`으로 고정되어 있어 1000행까지는 자동 반영됩니다(1분 주기 자동 새로고침, 또는 "지금 새로고침" 클릭). 1000행을 초과하면 `dashboard/index.html`의 `RANGE.gonggu` 값을 늘려주세요.

**Q. 셀러ID/카테고리ID를 입력했는데 주황/오류로 표시된다**
→ 마스터 시트(셀러마스터, 카테고리마스터, 채널마스터)에 해당 ID가 먼저 등록되어 있어야 합니다.

**Q. 수식이 깨졌다**
→ `node generate_sheet.mjs` 를 재실행해 템플릿을 다시 생성한 뒤, 입력했던 데이터만 새 파일로 옮기세요.
