🔖 공구 빠른등록 북마클릿

인스타그램 게시물을 보면서 북마크바의 버튼 한 번만 누르면, 제목·썸네일·원본링크가 자동으로 채워진 등록창이 열립니다. 최초 1회만 설치하면 계속 사용할 수 있습니다.

1. 빠른등록 페이지 주소 입력

아직 GitHub Pages를 켜지 않았다면, 우선 내 컴퓨터의 quick-add.html 파일 경로(file:///D:/Claude/gongu_monitor/dashboard/quick-add.html)를 넣어 테스트할 수 있습니다. 이후 실제 배포 주소가 정해지면 이 페이지에 다시 접속해 주소만 바꿔서 북마클릿을 새로 만들면 됩니다.

2. 북마클릿 버튼을 북마크바로 드래그

📌 공구 등록 ← 주소를 입력하면 버튼이 활성화됩니다
북마크바가 보이지 않으면 브라우저 설정에서 "북마크바 표시"를 켜주세요 (크롬: Ctrl+Shift+B).

3. 사용 방법

  1. 인스타그램에서 공동구매 게시물을 엽니다.
  2. 북마크바의 📌 공구 등록 버튼을 클릭합니다.
  3. 제품명·썸네일·셀러가 자동으로 채워진 팝업창이 뜹니다. 내용을 확인하고 시트에 등록하기를 누르면 끝입니다.

참고

  • 이 도구는 인스타그램이 페이지에 공개적으로 넣어둔 정보(제목, 대표 이미지)만 읽어옵니다. 로그인 정보나 비공개 데이터에는 접근하지 않습니다.
  • 셀러 자동 매칭은 셀러마스터 시트에 등록된 인스타그램 핸들 기준으로 동작합니다. 매칭이 안 되면 먼저 셀러마스터에 등록해주세요.
  • apps_script/Code.gs를 구글시트에 배포하고, quick-add.html 상단 CONFIG.APPS_SCRIPT_URL을 채워야 실제 등록이 동작합니다.
